# FRIENDS
Website dev and Mobile application for &amp;FRIENDS organisation.

## Overview
The &FRIENDS Digital Platform is a full-stack software development project. By offering a centralised platform for event promotion, ticket sales, customer engagement, and administrative management, the system seeks to modernise the administration of events presented by Mamakashaka &FRIENDS. 

The platform consists up of a mobile application and a responsive website with a shared Firebase backend. Through a safe and easy-to-use interface, consumers can browse events, buy tickets, upload proof of payment, manage reservations, and communicate with the organization. Tools for creating and managing events, confirming payments, answering consumer questions, keeping track of reservations, and producing reports are given to administrators.

# Client Problem
The client requires a consolidated digital platform that can increase user access to its services, events, and creative efforts. Users may find it challenging to locate pertinent events, obtain information, make reservations, and keep track of their interactions with the organization in the absence of an integrated platform.

Additionally, the system must facilitate administrative tasks and offer a structured method of managing users and other system data.

# Proposed Solution

The creation of a &FRIENDS website and mobile application that gives users a central location to access events and services is the suggested remedy.

Users of the platform will be able to:

- Look through and look for events.
- View comprehensive details on the event.
- Utilise the services that are offered.
- Make reservations for events and buy tickets.
- Provide payment details as needed.
- Get QR codes and digital tickets.
- Examine their reservations and transactions.
- Look around the gallery.
- Send queries.
- Control their profile.

Additionally, the system will include administrative features for managing users and platform data.

# Project Objectives

The project's objectives are to: 

1. Create a website that works with both desktop and mobile browsers. 
2. Create a mobile application for Android  and iOS. 
3. Provide a user experience that is accessible and easy to use. 
4. Centralise ticket sales and event administration. 
5. Boost correspondence between administrators and clients. 
6. Handle application data and user authentication securely. 
7. Use DevOps techniques and contemporary software engineering concepts. 
8. Use GitHub to demonstrate collaborative software development.

# Website and Mobile Application Scope
Website
The website provides the primary web-based interface for the &FRIENDS platform.

The website includes:

- Home page
- Services
- Events
- Event details
- About Us
- Contact Us
- Gallery
- Bookings
- User authentication
- Administrative functionality

The website is designed to provide users with access to event and service information through a structured and responsive interface.

Mobile Application
The mobile application extends the &FRIENDS platform to mobile users.

The planned application functionality includes:

- User registration and login
- Home dashboard
- Event browsing
- Event searching and filtering
- Event details
- Ticket purchasing
- Payment/proof-of-payment submission
- Payment status
- Digital QR-code tickets
- Booking history
- Transaction history
- Services
- Enquiries
- Gallery
- User profile management

The mobile application follows the same core system requirements as the website while providing a mobile-focused user experience.
