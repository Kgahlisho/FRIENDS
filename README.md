# FRIENDS
Website dev and Mobile application for &amp;FRIENDS organisation.

## Overview
The &FRIENDS Digital Platform is a full-stack software development project. By offering a centralised platform for event promotion, ticket sales, customer engagement, and administrative management, the system seeks to modernise the administration of events presented by Mamakashaka &FRIENDS. 

The platform consists up of a mobile application and a responsive website with a shared Firebase backend. Through a safe and easy-to-use interface, consumers can browse events, buy tickets, upload proof of payment, manage reservations, and communicate with the organization. Tools for creating and managing events, confirming payments, answering consumer questions, keeping track of reservations, and producing reports are given to administrators.

# Project Objectives

The project's objectives are to: 

1. Create a website that works with both desktop and mobile browsers. 
2. Create a mobile application for Android  and iOS. 
3. Provide a user experience that is accessible and easy to use. 
4. Centralise ticket sales and event administration. 
5. Boost correspondence between administrators and clients. 
6. Handle application data and user authentication securely. 
7. Use DevOps techniques and contemporary software engineering concepts. 
8. Use GitHub to demonstrate collaborative software development.
